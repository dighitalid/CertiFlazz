Pilih tool Dynamic Text di kiri, lalu klik pada sertifikat. Seret elemen untuk memindahkan.
Klik 2x bingkai foto untuk zoom/putar foto. Klik 2x pada teks untuk mengedit langsung (Enter = baris baru, Ctrl+Enter = simpan, Esc = batal).
Dynamic Foto: tarik titik putih di sudut/sisi untuk ubah ukuran (Shift = proporsional, Alt = dari tengah); tarik tombol ◜ di dalam sudut kiri atas untuk membulatkan.
Pintasan: Ctrl+Z urungkan · Ctrl+Y ulangi · Delete/Backspace hapus · Ctrl+D gandakan · Ctrl+C / V salin & tempel · Panah geser (Shift = jauh) · V T S F ganti tool · Esc batal · Ctrl+scroll zoom preview
